PROJECT CONCEPT

土地をつくる。関係をつくる。

3,000㎡を超える所有地を、いま使う場所と、未来へ残す場所に整理する。今回の計画は、道路の奥に位置する月極駐車場の一部から新しい収益資産をつくりながら、生産緑地や残地に次の選択肢を残す計画です。

そして、残す土地にも新しい役割を。生産緑地は地域にひらく市民農園として活かし、建物のCOMMON SPACEは昼に京都文化を体験する場、夕方には子ども食堂など地域にひらく居場所へ。建物・農地・地域の関係まで、一つの資産活用として考えます。

LAND STRATEGY

この土地の答えを、ひとつにしない。

今回の建築は、所有地全体の完成形ではありません。いま必要な場所に、いま必要な役割を与える。その一方で、残された土地には、次のタイミング、または次の世代が改めて選べる可能性を残す。建物の配置だけではなく、土地がこれから辿る時間まで見据えます。

GARDEN STRATEGY

建てない土地にも、役割を。

生産緑地として残る農地を、ただ「残す土地」にしない。地域の人も利用できる小区画の市民農園として活かし、農地としての役割を保ちながら、暮らしと地域に新しい価値を生む構想です。

賃貸住宅の主な入居ターゲットは、若い共働き世帯や子育て世帯を軸に据えたまま。農園は入居者を限定するためではなく、休日に土に触れる、子どもと育てる、収穫を楽しむ。そんな「選べる暮らし」を増やす付加価値として位置づけます。

COMMON GARDEN / CONCEPT

街のそばに、土の時間を。

住宅、文化、農。役割の違う場所を切り離すのではなく、それぞれに余白を持たせながらつなぐ。川沿いや農地が近い環境を、単なる立地上の弱点ではなく、この場所だから選べる暮らしへと翻訳します。

※市民農園の具体的な開設方式・区画・利用条件等は、農業委員会等との協議および必要な手続きを経て決定します。

COMMON SPACE

ひとつの空間に、ふたつ以上の時間を。

COMMON SPACEは、建物の外と住まいの間に置かれた、小さな地域の接点。昼と夕方で役割を変えながら、長く使い続けられる場を目指します。レジデンス側にも風除室を抜けた先に少しのゆとり空間を演出し、入居者様の生活に豊かさを生み出します。

DAYTIME

京都文化を、体験する。

書道、茶道、着付け、つまみ細工など。KOTORIが培ってきた文化体験を、より身近な場所へ。国内外の人が京都文化に触れ、つくり、持ち帰るための小さな文化拠点として活用します。

EVENING

夕方は、地域にひらく。

文化体験を行わない時間帯には、子ども食堂など、地域の子どもたちや家族が安心して立ち寄れる居場所としての活用も構想しています。ひとつの用途に固定せず、その時、その地域に必要な使い方へ変化できること。それも、この建物に残す「余白」です。

OWNER VALUE / FUTURE

土地には、続きがある。空間にも、続きがある。

15戸の賃貸住宅をつくることが、この土地のゴールではありません。収益資産をつくりながら、生産緑地には市民農園という役割を、COMMON SPACEには文化と地域の接点を持たせる。土地ごとに今の役割を与えながら、残地には次の判断ができる状態を残します。

相続税対策だけに答えを求めず、賃貸事業としての健全性を大切にする。建物を完成させるだけではなく、土地・農地・地域との関係まで、次の世代が選び直せる資産としてつないでいく。それが、この計画で考えたい資産活用です。

01 / INCOME収益15戸の賃貸住宅として、継続的な事業性をつくる。
02 / INHERITANCE相続節税だけでなく、次世代へ残す資産の質まで考える。
03 / LAND土地生産緑地・駐車場・残地に、それぞれの役割を持たせる。
04 / OPTIONS将来性建て切らず、次の判断ができる余白を残す。
05 / SUCCESSION資産承継大切な資産を、あらゆる可能性とともに次の世代へ。
